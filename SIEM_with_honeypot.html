SIEM solution that records RDP login attempts and creates a heatmap.

Project description:

I will create a Security Information and Event Management (SIEM) system in the cloud, alongside a virtual machine (VM) that will act as a honeypot. The VM will be deliberately configured to be highly vulnerable, allowing it to attract and log attacks from various IP addresses and countries worldwide. This data will be displayed on a map, highlighting the geographic origins of the attacks. The focus will be on failed Remote Desktop Protocol (RDP) login attempts.

Steps


1. Create an Azure Subscription: Set up an Azure subscription to host all the necessary resources.
2. Create a Virtual Machine in Azure: Deploy a VM in Azure.
3. Configure the Virtual Machine:
- Disable both the VM and Windows firewalls to expose it fully to the internet.
- This exposure will make the VM an attractive target for attackers, encouraging rapid discovery.
4. Set Up Log Analytics Workspace:
- Create a Log Analytics Workspace in Azure to collect and ingest logs from the virtual machine.
5. Set Up Azure Sentinel:
- Implement Azure Sentinel to create a visual map displaying the attack data, indicating the countries of origin.
6. Transform and Enrich Logs:
- Use PowerShell scripts to extract IP addresses from the Windows event logs.
- Send these IP addresses to a third-party API to obtain geographic data such as latitude, longitude, country, state, and province.
- Create custom logs in the VM incorporating this enriched geographic data.
By following these steps, I aim to provide a clear visualization of the global distribution of failed RDP login attempts, helping to identify potential threats.
